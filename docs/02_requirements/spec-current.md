# 現状仕様書（in Chrome版 v1.2.0）

## 1. 概要
YouTube の配信アーカイブのページで、チャットリプレイを読み込んで解析し、パネルに見どころ候補とタイムラインを出す Chrome 拡張機能（Manifest V3）。音声・画面の解析は行わない（in App版の担当）。

## 2. 使い方
- 導入：Chrome の拡張機能ページでデベロッパーモードをオンにし、`extension/` フォルダを読み込む。
- 動画ページの右下の「見どころ」ボタン、またはツールバーのアイコンでパネルを開き、「このアーカイブを解析」を押す。

## 3. チャットの取得
- 視聴ページ → チャットリプレイの初回ページ →「チャットのリプレイ（全件）」に切り替え → get_live_chat_replay で最後まで読む。未ログイン扱い（credentials: omit）で、yt-dlp と同じ要求を送る。
- 取得したチャットは動画ごとに chrome.storage.local に保存し、次に開いたときは自動で結果を出す（「再取得」で取り直す）。
- 配信中・チャットが無い・視聴制限のある動画は、分かりやすいエラーを出す。

## 4. 指標とスコア
| 指標 | 定義 |
|---|---|
| コメント量・加速度・同じコメントの流れる確率 | 共通指標仕様（shared/metrics-spec.md） |
| キーワード | 設定の「検知するワード」に一致したコメントの数 |
| スパチャ・メンバー | money・member の件数 |
| よく再生されている部分 | YouTube のヒートマップ（取得できた動画のみ） |
| 盛り上がりスコア | 重み speed 0.35、accel 0.15、same 0.15、keyword 0.20、money 0.05、heat 0.10（ヒートマップが無いときは、その重みを他に配り直す） |

## 5. 見どころの選び方
- スコアの高い区間から順に、minGapBins 区間以上離れたものを topN 件まで。
- ただし、次のどれかを満たす区間に限る：コメント速度が平常の minSpeed 倍以上／キーワードの急増／同じコメントの急増／スパチャ・メンバー3件以上／よく再生されている（0.6以上）。

## 6. パネル
- タイムライン：コメント量・加速度・同じコメ率・盛り上がりの4行。ヒートマップと折れ線の切り替え、表示範囲（全体／再生位置の前後15分／前半／後半）、パネルの幅を広げるボタン。
- マウスを乗せると、その区間の数値を表示。クリックすると、その場面の leadSec 秒前から動画を再生する。
- 赤い縦線＝再生位置（再生・シークに追従）。点線＝YouTube のシークバーで指している位置。黄色の▼＝見どころ候補。
- 候補の一覧：スコア順／時系列順、時刻を押すとその場面から再生し確認済みとして薄く表示、リストのコピー、動画のシークバーに黄色い印。

## 7. 設定画面
候補の出やすさ（minSpeed 1.3／1.5／2）、集計の細かさ（30／60／120秒）、候補の最大数、何秒前から再生するか、検知するワード（1行に「名前: パターン」）、保存したチャットの削除。
既定値：binSec 30、topN 20、leadSec 30、minGapBins 3、minSpeed 1.5。

## 8. 権限
storage、unlimitedStorage。content script は https://www.youtube.com/* に読み込む。

## 9. 制約
- YouTube の非公開の仕組みでチャットを読み込むため、YouTube の仕様変更で動かなくなることがある。
- メンバー限定・年齢制限・配信中の動画は解析できない。視聴者数の推移は取れない。

## 10. ファイル構成
| ファイル | 役割 |
|---|---|
| extension/manifest.json | 拡張機能の定義 |
| extension/fetcher.js | チャットリプレイの取得と読み取り |
| extension/analyzer.js | 指標・スコア・見どころの計算 |
| extension/content.js | パネル・タイムライン・動画との連動（ViewModel と View が混在） |
| extension/panel.css | パネルの見た目 |
| extension/options.html・options.js | 設定画面 |
| extension/background.js | アイコンでのパネル開閉、設定画面を開く |
