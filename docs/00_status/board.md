## 部長の判断記録
- 2026-10-30 INC-0001（/live/ URL 対応）：社長承認のもと /bugfix-pipeline で修正。/shorts/・/embed/ はチャットのリプレイが無いため対象外。詳細設計書 DD-0001 は作らない（URL判定1関数の不具合修正で、設計の変更を伴わないため。TS-0001 に経緯を明記済み）。
- 2026-10-30 週次動向調査（trends/2026-10-30.md）の回付：急ぎの依存更新なし。/deep-research「YouTube内部API（チャットリプレイ）破損の検知と代替手段」は、急ぎの破損がないため、無人の定期実行では実行せず次回の部長セッションに持ち越す。fetcher.js の subMenuItems[1] 添字固定の確認は、次回スモークテストの確認項目として保守運用課へ回す。添字固定の改善案は急がないため保留。ストア公開の有無は社長への確認事項として日報に書く。imageio-ffmpeg 同梱 ffmpeg の GPL 構成は開発用に限るため現状維持（配布物に入れる案が出たら社長判断）。

- 2026-10-30 社長の回答：Chrome ウェブストアへの公開予定あり。これを受け、研究課にストア規約（2026-08-01施行）と現状の収集内容・権限の照合を研究レポート（RS-0001）として依頼する。公開（リリース）そのものは、照合結果をそろえたうえで改めて社長判断とする。
- 2026-10-30 社長の決定（判断待ち #5）：A1 ストア公開は保留。当面は GitHub からクローンして使う「自己責任の拡張機能」として配布する体裁にする／B1 将来ストアに出すときは掲載名から「in Chrome」を外す／C1 プライバシーポリシーは GitHub Pages で公開、連絡先は Issue のみ（ストア公開時に実施）／D 開発者登録は保留／E unlimitedStorage の見直しは保留／F 画面での開示・説明書の整理は要件定義課へ回す（/feature-pipeline、ブランチ feat/github-distribution）／G ストア用スクリーンショットは見送り。
- 2026-10-30 REQ-0001（GitHub配布の体裁）承認を受けて：初回案内の追加は #5 の F で方針承認済みとみなし、設計・開発を進める。ただし使い方の変更を含むため、PR のマージは社長の承認後とする。ライセンス・持ち場（README.md・LICENSE）の追加・版数は判断待ち #7 に起票（設計・開発は並行して進め、該当箇所だけ回答待ち）。未追跡の docs/08_player/requests/PLY-0001-first-trial.md はプレイヤー代理課の作業物のため、本件のコミットに含めない。
